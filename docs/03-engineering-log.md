# Engineering log

Append one entry per working day. Five minutes, no polishing. This file is what
turns "I followed a tutorial" into "I can defend these decisions in an interview".

Copy the block below for each day.

---

## Day N — YYYY-MM-DD · Stage X

**Shipped:** what now works that did not yesterday (one line).

**Broke:** what failed, the exact error or symptom, and what the root cause was.
If nothing broke, you were not pushing.

**Learned:** the one concept you can now explain that you could not before.
Write it as a claim plus the evidence that made you believe it.

**Decision:** anything you chose and the alternative you rejected. (Feeds
`docs/02-stack.md`.)

**Tomorrow:** the single next step.

**Time:** ~h. **Spend:** $ (model API).

---

## Gate reviews

At the end of each stage, add:

**Stage gate X — pass/fail**
- Definition of done: every box ticked? (link to `PROGRESS.md`)
- Failure drills: which did you run, what did you observe?
- Explain-it test: 5 sentences, no jargon, as if to a skeptical senior engineer.
- Evidence filed in `projects/0X-*/evidence/`?
- If fail: what is the smallest fix, and which stretch item do you drop to pay for it?
